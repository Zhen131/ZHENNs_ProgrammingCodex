# Supervised Learning（监督学习）

## 一句话

Supervised Learning 用**带标签**（标准答案）的数据训练模型，让它学会从输入映射到正确输出。

## 背景：它出现前的问题

很多任务人一眼就能判断对错，却说不清判断规则——"这张图里是不是行人"就写不成 if-else。既然规则写不出来，那就让人提供大量"题目 + 答案"，让模型自己从中归纳规律。

## 核心机制

- 训练数据是成对的：输入 `x`（一张图片）+ 标签 `y`（"这里有行人"）。
- 模型给出预测 `ŷ`，用 Loss Function（损失函数）衡量 `ŷ` 和 `y` 的差距。
- 训练就是不断调整模型参数，让这个差距变小。

两类典型任务：

- **Classification（分类）**：输出类别，例如红灯 / 绿灯 / 行人 / 路障。
- **Regression（回归）**：输出连续值，例如预测房价、预测明天的收盘价。

## 典型使用场景

- 自动驾驶：图片提前人工标注红绿灯、行人、路障，模型学习识别这些物体。
- 垃圾邮件识别：邮件标注"是 / 不是垃圾邮件"。
- 数值预测：用历史数据预测价格、销量。

## 局限性

- **标注很贵**：自动驾驶需要人工逐帧画框，成本极高。
- 只能学到标签覆盖到的东西，没见过的情况容易判断错。
- 标签本身错了，模型会跟着学歪。

## 和其他概念的关系

- 与 [[Unsupervised Learning（无监督学习）]] 的区别：有没有标签。
- 与 [[Reinforcement Learning（强化学习）]] 的区别：监督学习每一步都告诉你"正确答案是什么"；强化学习只告诉你"做得好不好"，而且反馈可能延迟。
- 和 [[Deep Learning（深度学习）]] 组合就是深度监督学习，例如用 CNN 做图像识别——这种组合**需要**大量标注数据。
