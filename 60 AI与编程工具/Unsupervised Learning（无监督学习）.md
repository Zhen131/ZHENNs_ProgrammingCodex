# Unsupervised Learning（无监督学习）

## 一句话

Unsupervised Learning 处理**没有标签**的数据：没有标准答案，模型自己去找数据内部的结构——哪些东西相似、能分成几群、藏着什么规律。

## 背景：它出现前的问题

[[Supervised Learning（监督学习）]] 依赖人工标注，而标注又贵又慢；更重要的是，很多问题根本没有"标准答案"：用户应该分成几类？这些歌之间有什么隐藏的相似性？没人能提前给出标签，只能让模型自己从数据里找。

## 核心机制

- 先把对象表示成 Feature Vector（特征向量），例如把一个用户表示成"他听过哪些歌、每首听了多少次"。
- 用距离或相似度（如余弦相似度）衡量两个对象有多接近。
- 在此基础上做：
  - **Clustering（聚类）**：把相似的对象归成一群，例如 K-Means。
  - **Dimensionality Reduction（降维）**：把高维数据压缩成少数几个关键维度，方便观察和后续建模。

## 典型使用场景

- 音乐 App 的"猜你喜欢"：把用户转成特征向量，找到爱好相似的用户，把他们听过而你还没听过的歌推荐给你。这种思路叫 Collaborative Filtering（协同过滤）。
- 用户分群：电商按购买行为把用户自动分成几类，再分别运营。

> 精确一点说：协同过滤是推荐系统里的一类方法，工业实现常常混用多种技术（例如 Matrix Factorization（矩阵分解）是在拟合已知评分，更接近监督式训练）。这里借它说明的是无监督学习"不靠标签、自己找相似"的核心思路；最标准的无监督教学例子是聚类。

## 延伸：Self-Supervised Learning（自监督学习）

LLM 预训练的目标是"预测下一个 [[Token（语言处理单位）]]"，标签直接从文本本身生成，不需要人工标注。这叫 Self-Supervised Learning，通常被看作无监督学习的延伸，也是 [[Deep Learning（深度学习）]] 能在海量无标注数据上训练的关键原因之一。

早期的 [[N-Gram（N元语法）]] 其实在做同一件事——从无标注文本里预测下一个词，只不过靠的是计数统计而不是神经网络。

## 局限性

- **结果难评估**：没有标准答案可以对照，只能靠间接指标或人工判断。
- 聚出来的群不一定有业务意义，仍需要人来解释。
- 对特征表示很敏感：向量怎么构造，直接决定"相似"是什么意思。

## 关联

- [[Machine Learning（机器学习）]]：上位概念，无监督学习是三大范式之一。
- [[Supervised Learning（监督学习）]]：对照——区别在于有没有标签。
- [[Deep Learning（深度学习）]]：组合后成为深度无监督 / 自监督学习，不依赖大量人工标注。
- [[深度学习和强化学习有什么区别]]：澄清"深度学习一定需要标注数据"的误区。
- [[N-Gram（N元语法）]]：同样是"预测下一个词"，用计数统计实现的前神经网络方法。
