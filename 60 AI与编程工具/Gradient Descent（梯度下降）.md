# Gradient Descent（梯度下降）

## 一句话

Gradient Descent 是在看不到全局最低点的情况下，只凭当前位置的坡度，一小步一小步往下走，直到 [[Loss Function（损失函数）]] 不再下降的优化算法。几乎所有神经网络都靠它训练。

## 背景：它出现前的问题

模型参数动辄几百万、几十亿个。想找让 loss 最小的那组参数，既不可能穷举，也基本没有解析解（只有线性回归这类简单模型能直接解方程）。

需要一种方法：不要求看懂整个 loss 曲面，只靠局部信息就能持续改进。

## 它解决了什么

把"找全局最优"这个做不到的问题，换成"从当前位置找一个更好一点的位置"这个做得到的问题，然后重复几千几万次。它不保证找到最低点，但保证每一步都在往下走（学习率合适的前提下）。

## 核心机制

### Gradient（梯度）

Loss 对每一个参数的偏导数拼成的向量。它指向 loss **上升最快**的方向，所以往反方向走就是下降最快的方向。在神经网络里，梯度由 Backpropagation（反向传播）算出来，GD 只负责"拿到梯度之后怎么用"。

### 更新公式

```text
θ ← θ − η · ∇L(θ)
```

- `θ`：模型参数
- `∇L(θ)`：当前位置的梯度
- `η`：Learning Rate（学习率），也就是步长

### Learning Rate（学习率）：最重要的超参数

- **太小**：收敛极慢，可能在平坦区域原地踏步，训练几天 loss 几乎不动。
- **太大**：一步跨过谷底跳到对面坡上，loss 震荡甚至越来越大（发散）。
- 常见做法：先用大一点的学习率，随训练进行逐步衰减（Learning Rate Decay）；或者用 Adam 这类自适应优化器，给每个参数各自调步长。

### Batch（批）：拿多少数据算一次梯度

| 方式 | 每次用的数据量 | 特点 |
|---|---|---|
| Batch GD | 全部数据 | 梯度准，但一步极贵，大数据集算不动 |
| SGD（随机梯度下降） | 1 个样本 | 极快，但梯度噪声大，loss 曲线抖得厉害 |
| Mini-batch GD | 通常 32 ~ 512 个 | 实际工程里的默认做法，兼顾速度和稳定 |

关键理解：**一个 batch 算出的梯度只是真实梯度的一个带噪声的估计**。所以某一个 batch 的 loss 突然很高或很低，不说明什么；要看整体趋势。全部数据过一遍叫一个 Epoch（轮）。

### Local Minimum（局部最优）与 Saddle Point（鞍点）

神经网络的 loss 曲面是非凸的，有很多"坑"。GD 走到任何一个梯度为零的地方都会停下，不知道旁边还有更深的坑。

实际上在高维空间里，真正的局部最小点比想象中少，更多的是鞍点和大片平坦区——某些方向还能下降，但梯度小到接近零。SGD 的噪声在这里反而是帮手：随机抖动能把参数从平坦区或浅坑里推出去。

### Momentum（动量）

```text
v ← β · v + ∇L(θ)
θ ← θ − η · v
```

把历史梯度累积起来当作"速度"。多步梯度方向一致时越走越快；方向来回摆的噪声会互相抵消。效果是穿过小坑、减少震荡。Adam 优化器就是 Momentum 加上自适应学习率。

### 什么时候停

- 训练 loss 不再明显下降。
- 验证集 loss 开始回升——这时继续训练只是在背训练集，应该 Early Stopping（提前停止），见 [[Generalization（泛化）]]。

## 最小例子

用 numpy 拟合 `y = 2x`，看一眼梯度下降到底在做什么：

```python
import numpy as np

x = np.array([1.0, 2.0, 3.0, 4.0])
y = 2 * x                      # 真实规律：w = 2
w, lr = 0.0, 0.05              # 初始参数、学习率

for step in range(50):
    y_hat = w * x
    loss = np.mean((y_hat - y) ** 2)        # MSE
    grad = np.mean(2 * (y_hat - y) * x)     # dLoss/dw
    w -= lr * grad                          # 往负梯度方向走一步
    if step % 10 == 0:
        print(f"step {step:2d}  w={w:.3f}  loss={loss:.4f}")
```

把 `lr` 改成 `0.5` 再跑一次，就能亲眼看到学习率太大时 loss 爆炸。

## 典型使用场景

- 训练任何 [[Deep Learning（深度学习）]] 模型。
- 线性回归、逻辑回归等经典 [[Machine Learning（机器学习）]] 模型（数据大时比解方程划算）。
- 任何"有一个可微的目标、要调一堆参数"的问题。

## 局限性

- 要求 loss 对参数可微，或至少能估计梯度。
- 对学习率非常敏感，调不好要么不收敛、要么发散。
- 不保证全局最优，只保证局部改进。
- 迭代次数多，大模型训练动辄几天到几个月。

## 关联

- [[Loss Function（损失函数）]]：GD 最小化的对象；Loss 定义目标，GD 执行优化。
- [[Generalization（泛化）]]：训练 loss 降得低不是目的，验证集表现才是；Early Stopping 由此而来。
- [[Deep Learning（深度学习）]]：神经网络的参数全靠 GD（配合 Backpropagation）学出来。
- [[Supervised Learning（监督学习）]]：监督学习里"不断调整参数让差距变小"的具体做法就是 GD。
- [[Life as Gradient Descent（把人生当作梯度下降）]]：把局部更新、学习率、batch 噪声、动量、局部最优这些机制迁移到人生决策上的思维模型。
