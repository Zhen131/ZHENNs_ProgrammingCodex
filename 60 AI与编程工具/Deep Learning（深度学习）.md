# Deep Learning（深度学习）

## 一句话

Deep Learning 用多层堆叠的 Neural Network（神经网络）从原始数据中**自动提取特征**。它是一种"用什么模型来学"的技术，而不是和监督、无监督、强化学习并列的学习范式。

## 背景：它出现前的问题

传统 [[Machine Learning（机器学习）]] 严重依赖 Feature Engineering（特征工程）：人先把原始数据加工成有意义的特征（图像的边缘、K 线的 MACD 和均线），模型才能在这些特征上学习。

问题在于：特征的好坏决定了模型的上限，而人能想到、能写出来的特征是有限的。图片里的一只猫、K 线里某种隐藏的组合形态，很难靠人手写规则描述清楚。

## 它解决了什么

让模型直接吃原始数据（像素、文本、原始 K 线序列），在训练过程中自己学出有用的特征，不再完全依赖人工设计。

## 核心机制

- **Neural Network（神经网络）**：受人脑神经元启发的数学模型。每个"神经元"对输入做加权求和，再经过一个非线性函数；许多神经元组成一层，一层一层堆叠起来。
- **浅层 vs 深度**：层数很少的是浅层网络；堆叠很多层就是 Deep Neural Network（深度神经网络，DNN）。"深度"指的就是层数多。
- **层次化特征**：底层提取简单特征（图像的边缘、单根 K 线的涨跌），高层把简单特征组合成复杂、隐藏的模式（人脸、K 线组合形态、趋势与背离）。

## 可以套到任意一种学习范式上

| 组合 | 学习信号 | 是否需要大量人工标注 |
|---|---|---|
| 深度监督学习 | 标签，见 [[Supervised Learning（监督学习）]] | 需要 |
| 深度无监督 / 自监督学习 | 数据本身，见 [[Unsupervised Learning（无监督学习）]] | 不需要 |
| [[Deep Reinforcement Learning（深度强化学习）]] | 奖励，见 [[Reinforcement Learning（强化学习）]] | 不需要 |

所以"深度学习一定要标注数据"是误区：要不要标注取决于和哪个范式组合，而不取决于"深度"本身。

## 典型使用场景

- 图像识别、语音识别。
- LLM：文本先经过 [[Tokenization（分词）]] 变成 token ID 序列，再输入深度网络。
- 从原始 K 线时序中自动挖掘趋势、背离、K 线组合等模式。

## 局限性

- **吃数据、吃算力**：GPU 能大幅加速训练；小模型用 CPU 也能跑，只是慢一些。
- **可解释性差**：网络学到的特征藏在大量参数里，很难说清它"为什么"这样判断。
- **小数据上容易 Overfitting（过拟合）**：金融数据噪声大、有效样本少，网络很容易把噪声当成规律。
