# CSS（层叠样式表）

## 一句话

CSS 管网页"长什么样"：这个按钮是蓝的还是灰的、字多大、离左边多远、在手机上要不要换成一列。HTML 搭骨架，JavaScript 管行为，CSS 管皮肤。

## 背景：它出现前的问题

最早的网页只有 HTML，想让一个标题变红，就得在标签里直接写颜色。一百个标题就写一百遍。想全部改成蓝色，再改一百遍。样式和内容搅在一起，谁也动不了谁。

CSS 把样式抽出来单独写：你说一次"所有标题都是红的"，一百个标题就都红了。改颜色只改一处。

## 核心机制

一条 CSS 规则就是"选中谁 + 怎么改"：

```css
.price { color: red; font-size: 18px; }
```

`.price` 选中所有带这个 class 的元素，大括号里是要改的属性。浏览器读到这条规则，就把页面上所有价格数字渲染成红色 18 号字。

名字里的"层叠（Cascading）"说的是：同一个元素可能被好几条规则选中，浏览器按优先级决定听谁的。越具体的选择器、越靠后写的规则，优先级越高。初学时大部分"为什么我的样式不生效"都出在这里。

[[Tailwind CSS（Tailwind 样式工具）]] 不是另一种语言。它是把常用的 CSS 规则预先做成一堆现成的 class 名（`p-4`、`text-white`），你在 HTML 里直接拼，最后生成的还是 CSS。

## 典型使用场景

账本页面里，交易表格的列宽、盈亏数字的红绿色、按钮的圆角、手机上把两栏改成一栏——这些全是 CSS 的活。它不决定点击按钮后发生什么（那是 JavaScript / [[TypeScript（类型化 JavaScript）]]），也不决定这个按钮属于哪个页面（那是 [[Next.js（Next 应用框架）]]）。

## 局限性

项目一大，CSS 文件就散：规则写在十几个文件里，class 名撞车，没人敢删旧样式，怕哪个页面还在用。"层叠"这个机制本身也会让你排查半天某条规则到底被谁盖掉了。Tailwind 这类工具就是冲着这些痛点来的。

## 容易混淆

**Tailwind 和 CSS 是一回事吗？** 不是。CSS 是语言，Tailwind 是基于这个语言的工具包。详见 [[Tailwind 和 CSS 是一回事吗]]。
