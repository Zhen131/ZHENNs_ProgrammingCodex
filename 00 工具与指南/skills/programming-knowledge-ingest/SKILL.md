# 编程知识入库

1. 读仓库根目录 `CLAUDE.md`、`00 工具与指南/入库指南.md`、`00 工具与指南/写作规范.md`。规则全在这三个文件里。写之前读一张写作规范里列的标杆卡片。
2. 按入库指南「七、入库五步」执行：读材料 → 先搜 → 判断动作 → 建链接 → 检查。
3. 模板从 `00 工具与指南/templates/` 读。新卡 `status: 草稿`。
4. 跑 `python3 "00 工具与指南/check.py"`，零 ERROR。
5. 汇报：新建了哪几张、更新了哪几张旧卡、清单里有没有没过的项。
